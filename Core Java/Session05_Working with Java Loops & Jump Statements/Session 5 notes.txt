
# Looping/iterative statements

1. while loop

while(condition)
{
statments
inc/dec;
}

---

2. do.. while loop

do
{
statements;
inc/dec
}while(condition);

* without condition checking,
  at least once they can execute the statements in the while loop block.

---

3. For loop

for(initialization; condition; inc/dec)
{
statments;
}

---

which loop is preferred to use?

1. if you know the number of iteration — **for**
2. if you don’t the number of iteration + the loop termination based on condition — **while**
3. if you want to execute the loop at least once — **do-while**
