Data types

 1. Primitive: store a single value
    - number without decimal → byte, short, int, long 
    - decimal number → float, double
    - single character (single quote) → char
    - true/false → boolean 

 2. Non-primitive/ derived/ collections
    - String
    - ArrayList
    - HashMap
    - HashSet
    - etc. ….

---------

programming language types:

 1. Statistically typed programming language
    - ex. java
        int x = 100;
        x = “welcome”; //invalid to change the type of data

 2. dynamically typed programming language
    - ex. python
        x = 100
        x = “welcome” //valid
